# DiccionarioMultimediaLSM-Android
Interactive mobile app with AI tools, heart rate variability test, and LSM.

### 🇲🇽 / 🇪🇸 Versión en Español

## 📥 Guía de Descarga e Instalación (Android)

Esta aplicación se distribuye de manera directa (Sideloading) mediante un archivo APK firmado digitalmente. Para instalarla en tu dispositivo físico, sigue estos pasos:

1. **Descargar el archivo:**
   * Ve a la sección de [Releases](../../releases/latest) de este repositorio.
   * En el apartado de **Assets**, toca el archivo llamado `DiccionarioLSM_v1.0.1.apk` para descargarlo en tu teléfono.

2. **Otorgar permisos de instalación:**
   * Abre el archivo descargado desde tus notificaciones o desde la carpeta de *Descargas*.
   * Si es la primera vez que instalas una app fuera de la tienda, Android mostrará un mensaje de seguridad. Toca en **Configuración** (o Ajustes) y activa el interruptor de **"Permitir desde esta fuente"**. Regresa a la pantalla anterior.

3. **Confirmar la instalación (Play Protect):**
   * Toca el botón **Instalar**.
   * Es posible que Google Play Protect muestre una advertencia indicando que el desarrollador es desconocido. Toca en **Más detalles** y luego selecciona **"Instalar de todos modos"**.

4. **Permisos iniciales de la App:**
   * Al abrir la aplicación por primera vez, te solicitará permisos de **Cámara** (necesarios para el medidor VFC y la IA de reconocimiento de objetos) y de **Vibración** (para la retroalimentación del minijuego). Acéptalos para garantizar el correcto funcionamiento de todos los módulos.

### 🇺🇸 / 🇬🇧 English Version

## 📥 Download and Installation Guide (Android)

This application is distributed directly (Sideloading) via a digitally signed APK file. To install it on your physical device, follow these steps:

1. **Download the file:**
   * Go to the [Releases](../../releases/latest) section of this repository.
   * Under **Assets**, tap the file named `DiccionarioLSM_v1.0.1.apk` to download it to your phone.

2. **Grant installation permissions:**
   * Open the downloaded file from your notifications or your *Downloads* folder.
   * If this is your first time installing an app from outside the Play Store, Android will show a security prompt. Tap on **Settings** and toggle on **"Allow from this source"**. Go back to the previous screen.

3. **Confirm the installation (Play Protect):**
   * Tap the **Install** button.
   * Google Play Protect might show a warning stating the developer is unknown. Tap on **More details** and then select **"Install anyway"**.

4. **Initial App Permissions:**
   * Upon opening the app for the first time, it will request **Camera** permissions (required for the HRV/VFC scanner and AI object recognition) and **Vibration** permissions (for the interactive minigame). Please allow them to ensure all modules function correctly.
